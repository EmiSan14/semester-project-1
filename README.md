# Community Science Museum

The site for the fictional Community Science Museum teaching kids about science and nature.

## Description

The Community Science Museum page includes the start-page, ticket-page, exhibitions-page and information-page.
Included in these pages are:

- Specific cosmology exhibition
- Information about the museum, including open hours, accessibility, involvement opportunities, etc.
- Ticket page including ability to choose a date and reserve tickets for an upcoming visit (simulated)

## Built With

- HTML
- CSS
- JavaScript
